# Elektron Tanpa Alamat — video Teori Orbital Molekul (diatomik)

Film edukasi **Teori Orbital Molekul** (Kimia Kuantum S1 Kimia UNESA, RPS pertemuan 10), dibuat dengan [Remotion](https://remotion.dev). ±13 menit, 19 adegan, 2K 30 FPS, subtitle kata-per-kata.

Isi: oksigen cair di magnet → LCAO (H₂⁺) → orbital ikatan & antiikatan → H₂, He₂, orde ikatan → syarat penggabungan → σ & π dari 2p → diagram O₂ (paramagnetik terpecahkan) → pencampuran s–p (B₂) → deret Li₂–Ne₂ → ion O₂⁺/O₂⁻/O₂²⁻ → CO & hemoglobin → HOMO/LUMO → spektroskopi fotoelektron N₂ → oksigen singlet & terapi fotodinamik → nitrogen & Haber–Bosch.
